# hans — hanscloudserge.web.id

Personal portfolio for Muhammad Wildhan Anatayya ([@noticesa](https://t.me/noticesa)).

- **Live:** [hanscloudserge.web.id](https://hanscloudserge.web.id) (on-device via Termux + Cloudflare Tunnel) and `hans.vercel.app` (static mirror)
- **Stack:** Vanilla HTML/CSS (Plus Jakarta Sans), `server.py` stdlib only, no build step

## Deploy — Vercel (static)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/itswill00/hans)

1. Fork / clone this repo
2. Import in Vercel — framework preset: Other, no build command, output: `.`
3. `config.json` is static data (copy from `config.sample.json` if needed)

## Deploy — Termux (on-device, optional)

Requires private tunnel credentials — set `TUNNEL_TOKEN` or edit `deploy.sh`:

```bash
git clone https://github.com/itswill00/hans.git
cd hans
cp config.sample.json config.json
bash deploy.sh
# token printed at end: token <hex> -> use at /admin.html
```

Admin at `/admin.html` — login with token generated by `deploy.sh` (saved to `~/.config/hans-portfolio/admin_token`).

## Edit

Edit `config.sample.json` / `config.json` (profile, activities, i18n), `index.html` for layout, push — Vercel auto-deploys.
